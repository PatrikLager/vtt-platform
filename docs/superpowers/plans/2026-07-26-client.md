# Web Client Implementation Plan (sub-project 7)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an embedded web client that serves every role — spectator, player, DM — from the `vtt` binary, folding the event stream client-side so the wire stays the only state channel.

**Architecture:** A TypeScript fold mirroring `engine.Apply`'s observable semantics, pinned forever by a shared golden corpus that BOTH languages assert against. The client connects to the existing `/ws` wire (protojson, replay from sequence 0), and reads UI-only content (ability list, guides, adventure list) from new read-only HTTP GET endpoints on `vtt serve`. Built output is committed to `cmd/vtt/webdist/` and embedded with `go:embed`.

**Tech Stack:** TypeScript + Vite (no framework), `@bufbuild/protobuf` v2 generated types from `contract/gen/ts`, bun test, Playwright for e2e. Go side: `net/http`, `go:embed`, existing `identity.Verify`.

**Spec:** `docs/superpowers/specs/2026-07-26-client-design.md` (approved 2026-07-27).

## Key facts the implementer must not re-derive

These were established by source investigation on 2026-07-27. Trust them; verify only if something contradicts.

**`engine.State` has NO json tags** (`internal/engine/state.go:45-52`). `encoding/json` emits exact Go field names: `Scenes`, `Actors`, `Tokens`, `Sessions`, `Conditions`, `Notes`. Only `Actors` values are protobuf structs carrying snake_case tags (`actor_id`, `controller_id`, …) with `omitempty`.

**Three parity landmines** the TS fold must reproduce exactly:
1. `State.Sessions` is **not** initialized by `NewState` — it marshals as `null`, not `[]`, until the first `SessionStarted`.
2. Removing an actor's last condition leaves an **empty non-nil slice under the retained key**: `"Conditions": {"act-1": []}` — the key is NOT deleted.
3. `Resource` has `omitempty` on both fields: `{Current:0, Max:0}` marshals as `{}`; `{Current:0, Max:10}` marshals as `{"max":10}`.

**Sequence is a string in protojson**, a number in the state dump. `Envelope.sequence` is `"42"` on the wire (int64 → `bigint` in generated TS); `Session.StartSeq`/`EndSeq`/`Note.UpdatedSeq`/`ActorCondition.AppliedSeq` are plain JSON numbers in the dump.

**Auth is `?token=` query param only** (`internal/gateway/server.go:151`). No header auth exists anywhere. Task 3 introduces the first one.

**`Ruleset.Compiled` is a Go map** — iterate ability ids sorted for deterministic JSON.

**`*Expr` fields are not JSON-serializable.** Use the paired `*Src` strings (`RollSrc`, `VsSrc`, `DeltaExprSrc`) — they are the post-splice display text by design.

**There is no target-kind, description, or icon metadata on abilities.** `Targeting` is exactly `{Range int, MaxTargets int}`. See "Known limitation" under Task 3.

```go
// client/test/fold-parity.test.ts. Folding a recorded stream is fully
// deterministic in both languages, so this gate catches a Go fold change
// that would otherwise leave the goldens stale and the TS gate green.
func TestFoldGoldenCorpus(t *testing.T) {
	dirs, err := filepath.Glob("../../scenarios/goldens/*")
	if err != nil {
		t.Fatal(err)
	}
	if len(dirs) == 0 {
		t.Fatal("no golden scenarios found under scenarios/goldens/")
	}
	for _, dir := range dirs {
		t.Run(filepath.Base(dir), func(t *testing.T) {
			envs := readStream(t, filepath.Join(dir, "stream.json"))
			st, err := harness.Fold(envs)
			if err != nil {
				t.Fatalf("fold: %v", err)
			}
			got := dumpNormalized(t, st, headOf(envs))
			want, err := os.ReadFile(filepath.Join(dir, "state.json"))
			if err != nil {
				t.Fatal(err)
			}
			if string(got) != string(want) {
				t.Errorf("folded state does not match golden\n--- got ---\n%s\n--- want ---\n%s", got, want)
			}
		})
	}
}

func readStream(t *testing.T, path string) []*vttv1.Envelope {
	t.Helper()
	raw, err := os.ReadFile(path)
	if err != nil {
		t.Fatal(err)
	}
	var lines []json.RawMessage
	if err := json.Unmarshal(raw, &lines); err != nil {
		t.Fatal(err)
	}
	envs := make([]*vttv1.Envelope, 0, len(lines))
	for i, line := range lines {
		var env vttv1.Envelope
		if err := protojson.Unmarshal(line, &env); err != nil {
			t.Fatalf("envelope %d: %v", i, err)
		}
		envs = append(envs, &env)
	}
	return envs
}

func headOf(envs []*vttv1.Envelope) int64 {
	var head int64
	for _, e := range envs {
		if e.Sequence > head {
			head = e.Sequence
		}
	}
	return head
}
```

`dumpNormalized` must produce byte-identical output to `cmd/vtt`'s `writeDump`. Because `writeDump` is unexported in a different package, reimplement it here **exactly** and pin the duplication with a comment:

```go
// dumpNormalized mirrors cmd/vtt's writeDump byte-for-byte (state_dump.go:113).
// The duplication is forced: internal/harness may not import cmd/vtt (arch-lint
// allowlist [contract, engine, harness]). If writeDump changes, this must too —
// the golden corpus is what catches the divergence.
func dumpNormalized(t *testing.T, st any, head int64) []byte {
	t.Helper()
	raw, err := json.Marshal(st)
	if err != nil {
		t.Fatal(err)
	}
	fields := map[string]json.RawMessage{}
	if err := json.Unmarshal(raw, &fields); err != nil {
		t.Fatal(err)
	}
	headRaw, err := json.Marshal(head)
	if err != nil {
		t.Fatal(err)
	}
	fields["headSequence"] = headRaw
	var buf bytes.Buffer
	enc := json.NewEncoder(&buf)
	enc.SetIndent("", "  ")
	if err := enc.Encode(fields); err != nil {
		t.Fatal(err)
	}
	return buf.Bytes()
}
```

The normalizer:

```go
// normalizeStream replaces the four per-run-varying envelope fields with
// stable values so a regenerated corpus diffs only on real changes, and so
// the folded state's Session.ID matches the stream's sessionId.
func normalizeStream(envs []*vttv1.Envelope, idsByName map[string]string) []*vttv1.Envelope {
	nameByID := make(map[string]string, len(idsByName))
	for name, id := range idsByName {
		nameByID[id] = name
	}
	sessions := map[string]string{}
	out := make([]*vttv1.Envelope, 0, len(envs))
	for _, env := range envs {
		e, ok := proto.Clone(env).(*vttv1.Envelope)
		if !ok {
			panic("clone returned wrong type")
		}
		e.EventId = fmt.Sprintf("evt-%d", e.Sequence)
		e.OccurredAt = nil
		if e.ParticipantId != "" {
			if name, known := nameByID[e.ParticipantId]; known {
				e.ParticipantId = "p-" + name
			} else {
				e.ParticipantId = "p-unknown"
			}
		}
		if e.SessionId != "" {
			stable, seen := sessions[e.SessionId]
			if !seen {
				stable = fmt.Sprintf("sess-%d", len(sessions)+1)
				sessions[e.SessionId] = stable
			}
			e.SessionId = stable
		}
		out = append(out, e)
	}
	return out
}
```

Writing the stream: marshal each envelope with `protojson.Marshal`, collect as `[]json.RawMessage`, then `json.MarshalIndent(lines, "", "  ")` plus a trailing newline. Writing the state: fold the **normalized** slice with `harness.Fold`, then `writeDump(f, st, headOf(normalized))` — reused verbatim so goldens match the wire contract exactly.

**The fold contract — mirror these exactly** (from `internal/engine/apply.go`):

Two passes. Pass 1 collects retracted sequence ranges from every `eventsRetracted` payload, **inclusive** `[fromSequence, toSequence]`. Pass 2 walks in order, skipping retracted sequences and skipping `eventsRetracted` markers themselves, applying everything else. Unknown payload variants are **skipped, not fatal**.

*AMENDED 2026-08-30 — ONE pass.* Retraction left the platform on Patrik's ruling
of 2026-08-30 (`docs/superpowers/specs/2026-08-30-retraction-leaves-design.md`),
and `client/src/fold.ts` collapsed to a single pass in `d3e2f28`: walk in order,
apply each envelope, skip an unknown variant. Pass 1 existed only to collect
retracted ranges, and there are none — `eventsRetracted` left the contract in
`59542e1`, so it is not even an unknown variant to skip. All four folds in the
platform made the same collapse for the same reason (`engine.Apply` via
`campaign.foldEvents` and `FoldPrefix`, and `internal/harness`'s `Fold`). The
"unknown payload variants are skipped, not fatal" rule is unchanged and is the
forward-compatibility promise. The per-variant table below is also no longer
sixteen rows; `client/test/fold-unit.test.ts` and the shared golden corpus are
the live enumeration.

Per-variant behavior, all 16:

| Variant | Behavior |
|---|---|
| `sessionStarted` | Error if a session with `EndSeq === 0` exists. Append `{ID: env.sessionId, Name: payload.name, StartSeq: seq, EndSeq: 0}`. **ID comes from the envelope, not the payload.** |
| `sessionEnded` | Error if none open. Set `EndSeq = seq` on the **first** entry with `EndSeq === 0`. |
| `sceneCreated` | Error on duplicate id. Insert `{ID, Name, GridWidth, GridHeight}`. |
| `actorAdded` | Error if actor missing or id empty, or duplicate. Deep-copy the actor. |
| `tokenPlaced` | Errors checked **in this order**: duplicate token, unknown scene, unknown actor, null position. |
| `tokenMoved` | Error on unknown token or null `to`. Set `X`,`Y`. **`from` and `sceneId` are ignored entirely.** |
| `attackRolled`, `eventsRetracted`, `abilityUsed`, `adventureLoaded` | No-op. |
| `resourceChanged` | See below. |
| `conditionApplied` | Error on unknown actor or duplicate condition id. Append `{ID, Source, AppliedSeq: seq}`. **Append order preserved; never sorted.** |
| `narrationAdded` | **Validates but does not mutate.** A malformed narration fails the whole fold. |
| `noteUpserted` | Byte lengths: key 1..128, title ≤256, text 1..8192. Full replace. |
| `noteDeleted` | Error if key absent. Delete. |
| `conditionRemoved` | Error on unknown actor or absent condition. Splice out **first** match; **retain the key even when the slice becomes empty**. |

`resourceChanged` — the exact clamp:

```ts
// Mirrors engine.Apply's ResourceChanged (apply.go:124-155). The arithmetic is
// done in a wider type on purpose: Go computes in int64 so int32 cannot wrap
// before the clamp applies. JS numbers are safe for this range.
const res = actor.resources?.[p.resource];
if (!res) throw new FoldError(`resource changed for unknown resource "${p.resource}" on actor "${p.actorId}"`);
let computed = (res.current ?? 0) + (p.delta ?? 0);
if (computed < 0) computed = 0;
const max = res.max ?? 0;
if (max > 0 && computed > max) computed = max;   // max <= 0 means UNLIMITED
if (computed !== (p.newValue ?? 0)) {
  throw new FoldError(
    `resource "${p.resource}" on actor "${p.actorId}": event new_value ${p.newValue} does not match computed ${computed}`);
}
actor.resources[p.resource] = { current: computed, max: res.max };  // Max carried over, never from the event
```

`narrationAdded` validation (byte lengths via `new TextEncoder().encode(s).length`, **not** `.length`): text 1..8192; `as` ≤256; both anchors ≥0; `0/0` valid and unanchored; if either anchor is non-zero both must be; `from > to` invalid; `to >= env.sequence` invalid.

**Serialization to dump shape:** `Sessions` must be `null` when no session ever started, `Conditions` keys retained with `[]` values, `Resource` fields omitted when zero, top-level keys alphabetical with `headSequence` last, 2-space indent, trailing newline, and HTML escaping of `<`, `>`, `&` to `<`, `>`, `&` (Go's `SetEscapeHTML` default is on).
