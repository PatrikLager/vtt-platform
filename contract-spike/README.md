# Contract Format Spike

This spike builds three competing contract-format prototypes — protobuf (buf), JSON Schema 2020-12 (quicktype/ajv), and OpenAPI 3.1 (oapi-codegen/openapi-typescript) — to decide the schema format for the platform's Go/TypeScript/LLM-tool contract. The `fixtures/` directory contains five benchmark JSON files that all prototypes must be able to parse and produce, ensuring a shared contract format across Go, TypeScript, and other targets. Each prototype directory is throwaway evidence for [ADR-007](../docs/adr/007-contract-format.md), which records the scorecard and the accepted decision.
