# Adjudicated EQUIVALENT mutants: surviving mutations that no test can kill,
# because the mutated code is observationally identical to the original.
#
# Format:  <package>  <file>:<line>:<col>  <MUTATOR>
# followed by an indented reason line. Both are required — a bare entry is a
# parse error.
#
# ------------------------------------------------------------------------
# READ THIS BEFORE ADDING AN ENTRY.
#
# An "equivalent" verdict asserts that NO test can ever kill this mutant, so
# it forecloses writing one. A wrong entry is therefore worse than an
# unadjudicated survivor: it converts a real gap into a permanently excused
# one, in writing, with a confident-sounding justification.
#
# That is not hypothetical. Four mutants were adjudicated equivalent here on
# 2026-07-27 and TWO were wrong (conformance.go:319 and :325). The reasoning
# was that `json:"...,omitempty"` makes a nil map and an empty map marshal
# identically — true, and irrelevant, because the observable is not JSON:
# checkCompiledBatchGolden compares DECODED STRUCTS with reflect.DeepEqual,
# where nil map != empty map. A two-line fixture killed both.
#
# The test to apply, learned from that mistake: do not ask "is the output the
# same?" Ask "is there ANY observable — under DeepEqual, under a pointer
# comparison, under nil-ness, under identity — that distinguishes them?"
# The two entries below survive that test because the mutated branch assigns
# a scalar EQUAL to the value the variable already holds. The conformance
# pair did not, because make(map...) assigns a NEW OBJECT whose nil-ness is
# observable.
#
# If you cannot state the reason in one sentence that names the observable,
# the mutant is not equivalent — it is untested. Write the test.
# ------------------------------------------------------------------------
